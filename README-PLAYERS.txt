AZS SPEED CONTROLLER v1.1 - PORTABLE (Windows x64)
===================================================
Unofficial community utility for Azeroth Survivors.

QUICK START
1. Extract the entire ZIP to a folder. Do not run from inside the ZIP.
2. Start Azeroth Survivors.
3. Double-click AZSSpeedController.exe (keep AZSSpeedHook.dll beside it).
4. The overlay should show ONLINE / Connected.

CONTROLS
F6 = x1 normal speed
F7 = x2
F8 = x5
F9 = x10
F10 = compact / expanded overlay
F11 = minimize / restore overlay
Drag the window to move it across monitors.
Click X to exit; normal exit requests x1 speed.
Right-click for opacity and other options.

NOTES
- Windows 10/11 64-bit; test compatibility on your system.
- No Cheat Engine, Visual Studio or installer is required by design.
- The app loads its companion DLL into the game process to alter time functions.
  Some security software may flag this technique. Do not bypass your security
  protections blindly; inspect the published source if concerned.
- Exit normally to restore x1. Forced termination/crashes may not reset speed.
- If the game does not connect, ensure both files are extracted together and
  the game is running. Try restarting both programs.
- Configuration is stored in AZSSpeedController.ini beside the EXE.
- This software is provided as-is. Use only with the game developers' permission.
