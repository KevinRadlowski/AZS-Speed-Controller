# Contributing

Please open an issue describing the bug, game version, Windows version, steps to reproduce, expected and observed behavior, and screenshots/logs **without personal information**. For pull requests, keep the Windows x64 build working, avoid introducing installers or telemetry, update documentation/changelog, and describe manual game tests. Do not commit `build/`, `dist/`, or local `.ini` files. Avoid shipping modified game files. A repository license must be chosen before accepting outside contributions.
